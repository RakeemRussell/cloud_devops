# Never paste or commit

This repo is public. Keep all of these out of logs, notes, commits and chat:

- AWS access keys (start with AKIA or ASIA), secret keys, session tokens
- Private keys, passwords, API tokens, connection strings
- `.tfstate` contents
- AWS account IDs, email addresses, IP addresses

If a secret is ever pasted or committed: rotate or revoke it first, then clean up.
