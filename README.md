# cloud_devops

A public working log of my hands-on practice in DevOps and cloud infrastructure: Linux, networking,
Git, infrastructure as code, containers, Kubernetes, CI/CD and observability.

This repo was created in October 2026 and fills in week by week, so early sections are sparse.

## What is here

| File | What it holds |
|---|---|
| [`progress/progress.md`](progress/progress.md) | Weekly log: focus, what I shipped, hours actually logged, and what surprised me |
| [`progress/incident-journal.md`](progress/incident-journal.md) | Break/fix write-ups: symptom, first hypothesis, the evidence that confirmed the cause, fix, and how I'd prevent it |
| [`progress/decisions.md`](progress/decisions.md) | Non-obvious choices, with the alternatives I rejected and why |

## How I work

- Diagnose before fixing. Each incident records my first hypothesis, even when it was wrong.
- Time every break/fix, and write a prevention that changes a check or a default.
- Record a decision when I make it, with a condition for revisiting it.
