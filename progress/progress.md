# Progress log

One row per week, written on Sunday. The column that matters is **what surprised me**: surprise is
where my model was wrong.

## Weekly rows

| Week | Focus | Deliverable shipped | Gate | Hours | Figures redrawn | What surprised me |
|---|---|---|---|---|---|---|
| 1 | Linux I, Git | | | | | |
| 2 | | | | | | |

- **Deliverable shipped**: `y` or `n`, plus the repo link. "Nearly" is `n`.
- **Gate**: `—`, `pass`, or `fail: <the criterion, in one sentence>`. Only gate weeks (4, 9, 13, 17, 21, 26).
- **Hours**: actually logged, not planned.
- **Figures redrawn**: diagrams redrawn from memory this week, and where the order slipped.
- **What surprised me**: one sentence. Where a word stood in for a mechanism.

## Monthly retrospective (gate weeks: 4, 9, 13, 17, 21, 26)

Copy this block under the gate week's row and fill it in.

1. **Hours actually logged** vs the 4-8 per day target.
2. **The 70/30 ratio**: the fraction of time that was hands-on keyboard.
3. **Top 3 "Surprised" lines** from `incident-journal.md`.
4. **Weakest area**, and the specific thing I will do about it next month.
5. **Sustainability**: a rest day every week? If not, fix that before the next week starts.
6. **Figures redrawn cold**: every figure since the last gate, with the badge where it slipped.
